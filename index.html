Elixir with USB audio custom build

Installs your own build of Elixir (the one with the USB audio patch) on an M-VAVE FM-1 over USB, from this page. Chrome or Edge (Web MIDI). The file never leaves your computer.

Untested firmware. USB audio has not been tested in Elixir on a real FM-1. If a build crashes as it starts, the FM-1 can only be recovered with the FM-1-transporter. This page and the build are unofficial, with no warranty; Elixir's author hasn't made or reviewed them.

Connect the FM-1 directly with a USB data cable, close other apps that use MIDI (including a DAW), and allow MIDI (SysEx) when the browser asks. Don't unplug the cable or close this page while it writes.

1Check what your FM-1 runs

2Choose the build

This repo builds Elixir with the USB audio patches on GitHub, so there's nothing to build yourself: pick one of the latest builds. Either goes onto an FM-1 already running Elixir, Kettle or the official V15, and you can switch between them any time; updating Elixir keeps your projects, kit library and settings.

    If an install is cut off (cable pulled, page closed), the FM-1 stays in update mode. Plug it back in, choose the same build and press Install again to finish.

    3Use it on iOS
    
  
      
    
    1. Connect the FM-1 to the iPhone or iPad (USB-C, or Apple's Lightning to USB 3 camera adapter with power).
      2. 
    
    2. In an app that records from an audio interface (AUM, GarageBand, Loopy, Koala…), pick the FM-1 as the input.
      The stereo build sends the master mix at 44.1 or 48 kHz (the app picks). The 8-channel build shows up as eight
      inputs at 44.1 kHz: 1–2 the mix, 3–8 D1, D2, D3, SN, CY and the hats, each before its pan and sends.
      3. 
    
    3. 8 channels: on the FM-1, CONFIG → USB AUDIO switches inputs 1–2 from MIX to FX, the FX bus and reverb
      returns with the master chain (compressor, DIRT, DJ filter, STUTTER and the rest) and no dry sound. Record 3–8
      and 1–2 together for every voice dry plus the effects. FX mode only applies while an app records; the FM-1's own
      output stays the full mix.
      4. 
    
    4. The MASTER pot sets the level of inputs 1–2, so keep it up while recording. Inputs 3–8 don't follow it.
      5. 
    
    5. On the FM-1, open CONFIG → LOAD while a busy pattern plays and the app records, and note the CPU and PEAK
      figures: that's the one cost of USB audio nobody has measured yet.
      6.
